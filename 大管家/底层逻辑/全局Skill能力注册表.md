# 全局Skill能力注册表

> **唯一可信来源。** 仅可调用「已登记 且 已绑定专家」的 Skill；未绑定的 Skill 视为暂未启用，不得强行调用。
> 禁止自行创建、安装注册表以外的任何 Skill。

## 一、登记模板

```
【Skill登记】
- Skill 名称：<原话保留>
- 归属业务线：公共通用 / 数据 / 行业 / 信息收集 / 银发经济 / 旅游项目
- 功能描述：<一句话>
- 绑定专家：<专家代号，未绑定写「未绑定」>
- 状态：启用 / 暂未启用
- 登记时间：<YYYY-MM-DD>
```

## 二、调度优先级

1. 对应业务线的专属 Skill 优先，随任务下发给对应二级主管
2. 公共通用 Skill 可跨业务线调用，由超级总管家统一同步下达
3. 任务执行中发现遗漏 Skill，由二级主管申请、总管家补充下发，无需用户额外指令

## 三、调用与校验规则

1. 仅可调用本表内已登记、且已绑定专家的 Skill
2. 未绑定 → 告知用户「该 Skill 暂未启用」，不强行调用
3. 任务结束后，超级总管家校验所需 Skill 是否全部生效调用，缺失则要求补充执行
4. 返回结果须标注每个子任务对应的调用 Skill，保留可溯源性

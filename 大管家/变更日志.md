### 环境适配踩坑

| 问题 | 原因 | 解决 |
|---|---|---|
| 监听器语法错误 | PS 5.1 读无 BOM 的 UTF-8，中文按 ANSI 解析致语法崩溃 | 文件加 UTF-8 BOM |
| FileSystemWatcher 事件不触发 | 本机 Windows 文件系统通知不可靠 | 改用**轮询实现**（93 文件扫描仅 60ms，性能充裕） |
| 稳定期永远不稳定 | 监听器自身写日志被算作「持续变动」 | 排除日志目录；稳定期改为「以首轮变更集合为基准」判定 |
| bash 输出乱码 | PS 按 ANSI 读取 bash 的 UTF-8 输出 | 输出侧做 UTF-8→ANSI 转换；脚本内声明 LANG/LC_ALL |
| 备份日志被当成变更 | 运行时日志进了版本库 | `.gitignore` 排除 `大管家/备份日志/`、`.大管家/` |

| 问题 | 原因 | 解决 |
|---|---|---|
| 分片上传报 `1052 下载未完成上传的文件` | 自实现时把完整 `block_sha_list` 传给了分片请求 | **分片时 `block_sha_list` 必须传空数组 `[]`**（官方 upload_to_weiyun.py 的做法） |
| 分片后 offset 推进错位 | 自算 offset 推进 | 改为「每轮重新预上传拿 `channel_list`，用返回的 `offset`/`len` 定位分片」 |

| MCP 直连 401 | 本地代理端口/令牌轮换 | 从 `CODEBUDDY_MCP_CONFIG` 按 `"tencent-weiyun":` 精确切片取配置（**不要用正则贪婪匹配，会串到 github 段**） |
